# 🧭 Survival Guidance RAG  
*A Retrieval-Augmented Generation System for Evidence-Based Survival Advice*

---

## 📘 Overview  
**Survival Guidance RAG** is a modular end-to-end RAG pipeline that transforms raw video transcripts into a **searchable, explainable survival knowledge base**.  
Users can query the system via a **Streamlit interface**, get **evidence-backed answers** generated by Gemini, and monitor feedback through **Grafana dashboards** powered by PostgreSQL (AWS RDS).

> 💡 Built as a capstone project for the **DataTalks.Club ML Zoomcamp**, this project demonstrates full-stack MLOps practices — ingestion, RAG retrieval, LLM reasoning, monitoring, and deployment via Docker Compose.

---

## 🎯 Problem Description  

Online survival content (videos, blogs, forums) is **fragmented, redundant, and often inaccurate**.  
Finding **trustworthy, context-specific survival advice** during emergencies — floods, earthquakes, wildfires, or epidemics — is difficult.

This project solves that by building an intelligent retrieval system that:
- Finds **relevant, factual content** from survival video transcripts  
- Synthesizes concise, **source-backed answers** using an LLM  
- Captures **user feedback** to continuously improve system quality  

✅ **Result:** A transparent and reliable assistant that combines semantic search, retrieval augmentation, and real-time feedback monitoring.

## 🔍 Solution Summary  

| **Stage** | **Description** |
|:-----------|:----------------|
| **Ingestion & Chunking** | Extract and chunk transcripts into semantically meaningful segments with metadata (title, chapter, timestamp). |
| **Embedding & Storage** | Convert chunks to vector embeddings and store them in **Qdrant Cloud** for semantic retrieval. |
| **Retrieval-Augmented Generation** | FastAPI service retrieves top-matching chunks and crafts context-aware prompts for **Gemini API**. |
| **Feedback Loop** | User feedback (sentiment, clarity, satisfaction) logged to **PostgreSQL** and visualized via **Grafana Cloud**. |
| **Deployment** | Two lightweight containers — `rag_api` (FastAPI) and `streamlit_app` (UI) — orchestrated via **Docker Compose**. |

## 🧠 Key Features  

- ⚙️ Semantic retrieval pipeline built on **Qdrant + embeddings**  
- 🧾 Source-cited answers with **references and timestamps**  
- 🗣️ Context-aware LLM integration using **Gemini API**  
- 📊 Real-time user feedback stored in **AWS RDS** and visualized in [**Grafana Cloud**](https://sapientsapiens.grafana.net/public-dashboards/87d99596e7654e7aaef8d5c4535de037)  
- 🧰 Lightweight and portable architecture via **Docker Compose**  
- ☁️ Cloud-managed services for Qdrant, Postgres, and Grafana
